Student Management System - Phần mềm quản lí học sinh
Yêu cầu: 
  - Microsoft SQL Server 2019+
  - xampp version 8+
Cách sử dụng:
  1. mở microsoft sql server, tạo một database mới với tên "dbwebproject"
  2. mở xampp , chạy đồng thời apache và mysql
  3. vào địa chỉ localhost trên web và sử dụng.
